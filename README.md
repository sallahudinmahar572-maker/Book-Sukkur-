# Book Sukkur

A starter hotel/room booking web app for Sukkur, Pakistan.

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run:
   `npm install`
4. Start:
   `npm start`
5. Open `http://localhost:10000`

## Deploy on Render

Create a GitHub repository, upload this project, then create a Render Web Service.

- Build Command: `npm install`
- Start Command: `npm start`

The app listens on Render's `PORT` environment variable.

## Important before real production

This is an MVP starter. Before taking real payments or handling real customer data, add:
- admin authentication
- customer accounts
- secure sessions
- payment gateway
- email/SMS/WhatsApp confirmations
- hotel owner dashboard
- availability calendar and room inventory
- cancellation/refund rules
- privacy policy and terms
- HTTPS/security hardening
- persistent production database/storage

The seeded hotel images are demo images from Unsplash and should be replaced with images you have rights to use.
